# md.share

A simple, client-side markdown sharing tool. Write markdown, get a shareable URL - no accounts, no server storage.

**Try it now:** https://alexjacobs08.github.io/md-share/

## How it works

Your markdown content is compressed and stored directly in the URL. Anyone with the link sees exactly what you see. No database, no backend - just share the link.

## Features

- Live markdown preview with syntax highlighting
- URL-based storage using LZ-String compression
- URL shortening via is.gd
- Dark/light theme toggle
- Mobile responsive
